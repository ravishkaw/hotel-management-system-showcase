# 🏨 Hotel Management System (Showcase)

This is a **Hotel Management System** built with **React (frontend)** and **Spring Boot (backend)** as part of my final year project.  
The system handles **room reservations, event bookings, user management, and housekeeping management** with a clean modern interface.

---

## 🚀 Features

- User authentication & role-based access (Admin, Manager, Receptionist)
- Room reservations (view, book, cancel)
- Event reservations (banquets, conferences, etc.)
- Housekeeping management
- Admin dashboard with reports

---

## 🛠️ Tech Stack

**Frontend:** React 18, Vite, Ant Design, Axios  
**Backend:** Spring Boot, Java, REST API  
**Database:** MySQL  
**Security:** Session Based, BCrypt Passwords
